# Reference sources

Every reference and template in this plugin is a paraphrase, in our own
words, of frameworks described in:

**Technical Program Manager's Handbook, 2nd edition** — Packt Publishing,
ISBN 9781836200475.

No text from the book is reproduced. The templates are our own designs based
on the artifacts the book describes. The book is a commercial title; keep it
that way when editing these files.
